# NYC Block 3D

A 3D New York City block scene built with Three.js (r128), featuring a looping
Amazon delivery van doing package drop-offs. Originally built in a Claude
conversation on April 27, 2026.

## Main scene

**[`index.html`](index.html)** — the final combined scene (~11,500 lines,
self-contained). Open it in a browser, no build step needed.

## Repo layout

- `index.html` — final version (`NYC_Block_Full_Combined (2)` from the original session)
- `versions/` — every iteration from the project: Full_Combined revisions,
  Spiral and AmbaFlex conveyor variants, the 5-floor conveyor delivery system,
  underground/building combos, placeholders, and the tour recorder
- `videos/` — two recorded camera tours of the scene
